【视频简介】Algorithm Competition Assistant · 第一期：整体介绍
================================================================

这期视频给大家整体介绍一款 Sublime Text 算法竞赛本地测评插件——
Algorithm Competition Assistant（算法竞赛助手）。

它能做什么
----------------------------------------------------------------
· 一键抓题：浏览器里装好 Competitive Companion 扩展，点一下扩展图标，
  题面、样例、时空限制直接进编辑器；也可以用 Ctrl+Alt+Shift+F 从 URL 抓取
· 本地判题：Ctrl+Alt+B 运行，逐测试点给出 AC/WA/TLE/MLE/RE 等判定、
  用时与内存，右侧面板一目了然
· 文件输入输出：CSP/NOI 的 freopen 题按题设置一次即可
· 对拍、练习统计、比赛计时器、Benchmark、模板片段等刷题工具箱
· 界面中英文双语，随时切换

怎么安装
----------------------------------------------------------------
插件已被官方 Package Control 收录：
1. Ctrl+Shift+P 打开命令面板
2. 输入 Package Control: Install Package 回车
3. 搜索 Algorithm Competition Assistant 回车安装，装完即用
