Algorithm Competition Assistant —— Sublime Text 的算法竞赛本地测评插件

视频里演示的一切都是真实操作：从 Package Control 安装插件，到用 Competitive Companion 从洛谷题目页一键抓取样例，再到贴上代码、Ctrl+Alt+B 运行判题。

【安装】
Ctrl+Shift+P → Package Control: Install Package → 搜索 Algorithm Competition Assistant → 回车，即装即用。官方 Package Control 已收录。

【抓题】
浏览器安装 Competitive Companion 扩展，在其设置里的端口列表中加入 12345；Sublime 启动后插件会自动监听。打开题目页，点一下扩展（或按 Ctrl+Shift+U），回到编辑器按 Ctrl+Alt+L，一题一个文件，题面信息和样例自动就位。

【运行与判题】
Ctrl+Alt+B 按配置的编译命令和运行命令跑全部样例，每个测试点给出判定、用时和内存；用时和内存都按真实进程测量，不是估算。程序崩溃时能定位到出错的源码行，编译带缓存。

【实话实说】
这个插件基于 FastOlympicCoding 开发，判题结果的显示方式参考了 cph-ng，浏览器抓题的思路来自 FastOlympicCodingHook。它不做题，也不联网判题，只把本地调试这件事做顺手。
